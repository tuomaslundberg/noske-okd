# NoSketchEngine Deployment Verification — HPLT Toy Corpus

All six checks **PASS**. Details below.

**Check 1 — Page loads: PASS**
The Crystal UI loaded cleanly. Page title: `Select corpus | Sketch Engine`. The corpus selector ("SELECT CORPUS" heading with a search box) is visible, and under a "FREE CORPORA" panel the corpus is listed.

**Check 2 — Corpus selector: PASS**
"HPLT Toy" is listed as an available corpus, shown as `HPLT Toy — 4,097,003 words` with an OPEN button. Selecting it loaded the dashboard at `#dashboard?corpname=hplt_toy` (internal corpus name `hplt_toy` confirmed in the URL). The dashboard offered Concordance, Wordlist, Keywords, and Text type analysis tools.

**Check 3 — Basic word search: PASS**
CQL query `[word="ja"]` returned **164,773 hits** (38,713.32 per million tokens, 3.9%). Concordance lines appear in KWIC view and are genuine Finnish web text — e.g. fragments like "KRIISITOIMINTAOHJE lippukunnille ja piirin luottamushenkilöille", "kriisiviestintä", "Traumaattiset tilanteet", "psyykkinen ensiapu". The keyword "ja" (Finnish "and") is correctly highlighted in context.

**Check 4 — Frequency list: PASS**
The Wordlist returned a frequency list of **667,295 items / 4,256,235 total frequency**. The top entries are exactly the expected high-frequency Finnish function words: ja (164,773), on (97,378), että (28,057), ei (24,827), tai (24,101), myös, ovat, sekä, voi, oli, ole, kuin, mutta, plus items like Suomen, esimerkiksi, kaikki. This is a valid Finnish frequency list.

**Check 5 — Structural attribute filter: PASS**
CQL query `[word=".*"] within <doc lang="fin_Latn"/>` returned **2,491,846 hits** (585,457.8 per million tokens, 59%). Results returned correctly and show `<s>` sentence-boundary structure tags interspersed with Finnish tokens. Importantly, the match count is ~59% of the corpus rather than 100%, indicating the `lang` structural attribute is acting as a real filter (selecting only `fin_Latn` documents), which confirms the structural attributes (`doc`, `lang`) are indexed and queryable.

**Check 6 — Error check: PASS (no application errors)**
No visible error messages, broken UI elements, or empty-corpus indicators were observed on any page. The corpus is clearly populated (4.1M words, non-zero results on every query).

The browser console did log 29 identical exceptions, all verbatim:

> `Error: A listener indicated an asynchronous response by returning true, but the message channel closed before a response was received`

This is a well-known benign Chrome browser-extension messaging artifact (not generated by the NoSketchEngine application). There were no application-level errors — no HTTP 4xx/5xx, no CQL parse errors, and no corpus-loading failures.

**Summary:** 6/6 checks pass. The HPLT Toy corpus is loaded and fully functional — concordance search, frequency wordlist, and structural-attribute filtering all work correctly, and the data is authentic Finnish web text. One note: the page shows a "You are using NoSketch Engine. These tools are only available in Sketch Engine" message for the Keywords / Text type analysis tools, which is expected behavior for a NoSketchEngine deployment and not an error.
